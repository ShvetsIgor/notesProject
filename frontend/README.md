# Frontend

Web-Client for application `My Plans` 

### Current requirements

- Node.js
- Started backend

### Commands

- `npm install` install the dependencies.
- `npm run dev` - runs the dev server.
- `npm run build` - builds the project.

### Environment

- `http://localhost:5173` opens the application.
- requests to API goes via `/api/` and redirects to proxy on `http://localhost:3050`, so the backend must be running.
